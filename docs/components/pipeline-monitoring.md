# Recording processing

Staff use `/recordings` to find processing work and open `/recordings/<recordingId>` to see the recording, its Clip planning runs and its clips. Each clip links to `/recordings/<recordingId>/clips/<clipId>/processing`, where staff see the clip's stages and retries.

The [recording and clip design](clip-review-and-datasets.md) describes status, run history, costs and scope. The [stage retry design](stage-reruns.md) describes how the server plans and authorizes retries. [Recipes](device-profiles-and-recipe-selection.md) explains recipe definitions and capture sources.
